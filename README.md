# 크로노 바스티온 3D (Chrono Bastion) : 전술 유물 디펜스 및 드론 액션

- **Live Play URL**: https://kevin9327.github.io/chrono-bastion-3d/
- **장르**: 전략·디펜스 / 3D 웹게임 (Three.js WebGL + WebAudio Synth)
- **핵심 시스템**:
  1. **3D 성채 타일 레이캐스팅 포탑 건설·강화**: 아크 프리즘 탑, 중력 우물 포탑, 크로노 감속장, 궤도 레일건 4종 배치 및 레벨업
  2. **유물 배수(Chips × Mult) 시너지 드래프트**: 웨이브 클리어 또는 에테르 연성 시 3장의 유물 카드 중 1장을 선택해 기본 화력 칩(Chips)과 배수(Mult)를 곱연산으로 결합
  3. **실시간 지휘 드론 조작**: WASD / 방향키 / 모바일 터치 패드로 드론을 이동하며 자동 근접 사격 및 E키 광역 EMP 노바 충격파 방출
